# Business Model

Revenue is deferred for the MVP (goal = engagement; see [02_MVP.md](02_MVP.md)).
Below is the target model, split B2C / B2B per Hugo's proposal.

## B2C
- Premium subscription (alerts, history, AI)
- Affiliate commissions
- Cashback partnerships
- Reward redemption (coupon/product partnerships; see [10_Rewards_And_Engagement.md](10_Rewards_And_Engagement.md))

## B2B
- Sponsored products
- Sponsored markets / placements
- Market-facing intelligence dashboard
- Price API

Key Metrics:
- Monthly active users
- Receipts imported
- Savings generated
- Affiliate conversion
- Reward engagement / retention (DAU)
